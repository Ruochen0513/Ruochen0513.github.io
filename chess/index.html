接力规则与和棋说明

所有访客共用一盘棋，白方先行，之后黑白交替。同一 IP 不能连续落子，等其他 IP 落子后可再次参与；同一网络下的不同设备可能共用 IP。服务端使用 IP 的加密标识执行限制，不公开完整 IP。

支持将军、将死、逼和、王车易位、吃过路兵和升变为后／车／象／马。三次重复或 50 回合无吃子、无兵移动时，轮到的一方可以声明和棋；五次重复或 75 回合时自动和棋，将死优先。没有棋钟，不会因离线超时判负。

棋谱中的每一着都可点击回放。回看期间不能落子；点击“回到当前棋局”即可继续。结束的棋局会自动存入历史，也可以下载 PGN。
